# PWA (Progressive Web App) Guide

## Overview

HealthCore is configured as a **Progressive Web App** using `vite-plugin-pwa`. This means users can install it directly from the browser on their phone, tablet, or desktop — and it will behave like a native app (offline capability, fullscreen, no browser UI).

## How it Works

The PWA is powered by three components:

1. **Web App Manifest** (`vite.config.ts`): Tells browsers the app name, icons, colors, and display mode.
2. **Service Worker** (auto-generated): Caches the app's static assets for offline access.
3. **Icons** (`public/icon-192.png`, `public/icon-512.png`): Used on the home screen after installation.

## Building for Production

> [!IMPORTANT]  
> The PWA service worker does **not** activate in `npm run dev` mode. You must build and preview the production output to test it.

```bash
cd apps/health-core
npm run build
npm run preview
```

The preview server will start at `http://localhost:4173`. Open this in Chrome and you should see an **"Install"** icon in the address bar.

## 📱 Testing on Your Phone (LAN Tutorial)

This lets you test the full PWA experience on your own device — as if it were hosted in production.

### Step 1: Find your computer's local IP address

On Windows, open a terminal and run:
```powershell
ipconfig
```
Look for the **IPv4 Address** under your active network adapter (e.g., `192.168.1.105`).

### Step 2: Start the dev server exposed to your network

```bash
cd apps/health-core
npm run dev
```

You'll see output like:
```
  ➜  Local:   https://localhost:5173/
  ➜  Network: https://192.168.1.105:5173/
```

### Step 3: Open the URL on your phone

1. Make sure **your phone is connected to the same Wi-Fi network** as your computer.
2. Open your phone's browser and navigate to the **Network** URL (e.g., `https://192.168.1.105:5173`).
3. **⚠️ Security Warning:** Since we are using a self-signed certificate for development, you will see a warning. 
   - On Chrome (Android): Tap **Advanced** and then **"Proceed..."**
   - On Safari (iOS): Tap **Show Details** and then **"Visit this website"**

---

### Step 4: Install to Home Screen
**Chrome (Android) requires HTTPS to show the "Install" prompt.** Since we have HTTPS enabled in dev mode, it will work once you trust the certificate.
**On Android (Chrome):**
1. Tap the menu button (⋮)
2. Select **"Add to Home screen"** or **"Install app"**
3. The app will appear as an icon on your home screen

**On iOS (Safari):**
> [!NOTE]  
> On iOS, you **must use Safari** for PWA installation. Chrome on iOS cannot install PWAs.
1. Tap the **Share** button (the square with an arrow)
2. Scroll down and tap **"Add to Home Screen"**
3. Tap **"Add"** in the top right corner

### Step 5: Launch from the Home Screen

Tap the newly added HealthCore icon. It will open in **standalone mode** — no browser address bar — just like a native app.
